# output

Working area for `../rollcat.py`. Numbered takes land here, joined files when
takes are strung into one, and `dat.json` - the record of what each take was
made from, which is what lets a session be resumed instead of redone.

Everything in here is generated. Emptying it just means starting over; leaving
it alone means the next run picks up where the last one stopped. Nothing in this
directory is versioned on purpose: the text and the settings that produced it
are the part worth keeping.
