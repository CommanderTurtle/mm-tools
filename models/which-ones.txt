MM Tools model downloader and inventory
=======================================

`download_models.py` resolves `MODELS` from its own tracked location, so it can
be launched from any working directory and still targets `<mm-tools>/models`.
Before every selected download it explicitly creates the complete destination
with `parents=True`. A fresh clone therefore does not need pre-existing `qwen`,
`text-only`, `kijai`, `redesign/weights`, or PaddleX directories.
Current Hugging Face Hub writes real files into `local_dir`; older Hub releases
receive their former `local_dir_use_symlinks=False` compatibility flag only
when that argument still exists.

Create the small downloader environment once:

```bash
cd ~/multimedia/models
uv venv --python 3.12 --seed --managed-python .venv
source .venv/bin/activate
uv pip install -U huggingface_hub hf_xet
```

Interactive mode asks for the file/Xet worker count first, then presents the
bundle selection. Press Enter at the selection prompt to retain the original
behavior and download everything:

```bash
uv run download_models.py
```

The same choices work non-interactively by number or name:

```bash
uv run download_models.py --list
uv run download_models.py 2,6,10 --workers 24
uv run download_models.py minimax stableaudio
uv run download_models.py all --yes --workers 24
```

Bundle selection numbers are deliberately separate from the 40 inventory
numbers below. Each bundle includes every artifact needed by that runtime.

```text
 1  ideogram     inventory 1-3, 40
 2  longcat      inventory 4-5
 3  muscriptor   inventory 6-7
 4  musvit       inventory 8-9
 5  whisper      inventory 10
 6  translate    inventory 11-13
 7  redesign     inventory 14-19 and 24-31
 8  kijai        inventory 20-23 (standalone V2V extras)
 9  acestep      inventory 32-34
10  minimax      inventory 35 and 40
11  stableaudio  inventory 36-37
12  symphony     inventory 38
13  vocalrender  inventory 39
```

The inventory mirrors all 40 artifact definitions in the downloader. Trees
show files or major component directories expected from a fresh run; an
ellipsis means the remainder of that repository snapshot is retained in the
same folder. Model use remains governed by each upstream model license.
