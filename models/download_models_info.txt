Create and activate a small uv environment in this directory, then install
huggingface_hub and its current Rust Xet transport before running
download_models.py:

  uv venv --python 3.12.10 --seed --managed-python .venv
  source .venv/bin/activate
  uv pip install huggingface_hub hf_xet
  uv run download_models.py

The first question sets both file-download and Xet Tokio workers. The script
then presents numbered project bundles; press Enter for all models. Use
`uv run download_models.py all --yes --workers 24` for a non-interactive full
run. `hf_transfer` is a legacy transport and is not used by current Hub 1.x.
It is stateful and resumable through snapshot_download. Run it again after an
interrupted transfer with the same bundle selection. It recreates the exact
model and ReDesign weight paths expected by this monorepo, does not prune
older files, and does not create project venvs. Selecting `translate` migrates
the former `text-only/anhbn--raX-Translator-V1.0-GGUF` directory after any
interactive confirmation (or directly with `--yes`) when the canonical
destination does not yet exist.

Notice: downloading a model binds the downloader to that model repository's
upstream terms. Model artifacts are not part of this AGPLv3 source tree.
